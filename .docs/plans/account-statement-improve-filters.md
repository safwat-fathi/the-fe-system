# خطة تحسين فلاتر كشف الحساب

## المشاكل المطلوب حلها

1. كشف الحساب لا يفرز حسب رقم الحساب - المشكلة في API call
2. توحيد شكل الخانات (الحقول)
3. تحسين حقل رقم الحساب مع بحث و pagination

## التغييرات المطلوبة

### 1. إصلاح مشكلة التصفية حسب رقم الحساب
- التحقق من أن الـ API call يرسل `acc` بشكل صحيح
- قد تكون المشكلة أن API يتوقع `acc_id` وليس `id`
- التحقق من البنية الصحيحة للـ API parameters

### 2. توحيد شكل الحقول
- جعل جميع الحقول بنفس الحجم والارتفاع
- استخدام نفس الـ styling للحقول
- توحيد الـ labels

### 3. تحسين حقل رقم الحساب
- استبدال AsyncCreatableSelect بـ Input مع Autocomplete من HeroUI
- أو استخدام Modal مع جدول للبحث مع pagination
- إضافة إمكانية البحث في رقم الحساب واسم الحساب
- إضافة pagination للنتائج

## الملفات المتأثرة
- `app/(pages)/reports/account-statement/components/AccountStatementClient.tsx`

## الحل المقترح
- استخدام Input مع Modal يحتوي على جدول للحسابات
- البحث الفوري أثناء الكتابة
- Pagination للنتائج
- اختيار الحساب من الجدول
