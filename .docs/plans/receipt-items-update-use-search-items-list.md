# Goal
- ربط قائمة أصناف الذهب في سندات الاستلام/التسليم مع واجهة `SearchItemsList` (مع ترقيم الصفحات والبحث) لضمان استخدام المصدر الصحيح للبيانات.

# Plan
- إضافة دالة خدمة جديدة في `services/api/item.service.ts` تستدعي `SearchItemsList` مع معاملات الصفحة والبحث (xcom_id، query) وتُرجع نفس الشكل الموحّد للأصناف (الرمز، الاسم، الوزن، الوزن المعاير، السعر، k/purity).
- تحديث منطق تحميل الأصناف في `hooks/useReceiptDeliveryVoucherForm` ليستخدم الدالة الجديدة في البحث والتحميل التراكمي، مع اعتماد `next/count` لتحديد `hasMore` والحفاظ على التهيئة الحالية للحقل (الكود/الاسم/k/الوزن).
- اختبار يدوي سريع لسير البحث والتحميل (فتح القائمة بدون بحث، البحث بنص، تحميل المزيد) في شاشتي الاستلام والتسليم للتأكد من ظهور الأصناف والقيم المرتبطة كما هو متوقع.
