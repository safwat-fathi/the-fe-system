# خطة تبسيط فلاتر كشف الحساب

## الهدف
تبسيط فلاتر البحث في صفحة كشف الحساب والاحتفاظ فقط بالحقول الأساسية التالية:
- من تاريخ
- إلى تاريخ
- رقم الحساب واسم الحساب (حقل واحد للبحث)
- زر البحث

## التغييرات المطلوبة

### 1. إزالة عناصر الفلترة غير الضرورية
- إزالة Switch "تحليل متقدم" (advancedAnalysis)
- إزالة Select "نوع التصفية" (filterType)
- إزالة Select "خيارات التصفية" (filterOptions)
- إزالة Input "مشروع: خيارات التصفية" (project)
- إزالة زر "إعادة تعيين" (resetFilters)

### 2. تنظيف الكود
- إزالة حالات (states) غير المستخدمة:
  - `advancedAnalysis`
  - `filterType`
  - `filterOptions`
  - `project`
- إزالة دالة `resetFilters` أو تبسيطها
- إزالة الـ Switch import إذا لم يُعد مستخدماً

### 3. تحسين التخطيط
- ترتيب الحقول بجانب بعضها بشكل جميل ومرتب
- استخدام Grid أو Flexbox لتنسيق الحقول بشكل متناسق
- تحسين المسافات والتنسيق العام

## الملفات المتأثرة
- `app/(pages)/reports/account-statement/components/AccountStatementClient.tsx`

## المخاطر
- لا توجد مخاطر كبيرة لأن العناصر المزالة لا تُستخدم في منطق البحث الأساسي
- التأكد من أن دالة `handleSearch` لا تعتمد على القيم المزالة

## الاختبار
- التأكد من أن البحث يعمل بشكل صحيح مع الحقول المتبقية
- التأكد من أن التخطيط يبدو جميلاً ومرتباً
